# vquotes

**Vietnamese Quotes Open Database** — Entertainment, Literature, Famous People, Politics, etc.

All data is under CC0 license — free for anyone to use, share, and build upon.

### Tiếng Việt
**Cơ sở dữ liệu mở trích dẫn Việt Nam** — Giải trí, Văn học, Người nổi tiếng, Chính trị, v.v.

Dữ liệu được cấp phép mở (CC0) để ai cũng có thể sử dụng, chia sẻ và xây dựng ứng dụng.
