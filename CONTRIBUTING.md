# Contributing Guide / Hướng dẫn đóng góp

## English
Thank you for wanting to contribute to **vquotes**!

### Quick contribution process
1. Fork this repo
2. Create a new JSON file inside the `/quotes/` folder (use the template below)
3. Commit with a clear message
4. Open a Pull Request

All Pull Requests are manually reviewed for accuracy and legal compliance with Vietnamese law (only publicly verifiable sources, no historical distortion).

### JSON Template
See the **JSON Schema** section in README.md.

**We only accept quotes with clear public sources.**

## Tiếng Việt
Cảm ơn bạn đã muốn đóng góp vào **vquotes**!

### Quy trình đóng góp nhanh
1. Fork repo này
2. Tạo file JSON mới trong thư mục `/quotes/`
3. Commit với message rõ ràng
4. Mở Pull Request

Mọi PR sẽ được duyệt thủ công để đảm bảo tính chính xác và tuân thủ pháp luật Việt Nam.
