# Contributing Guide / Hướng dẫn đóng góp

## English
Thank you for wanting to contribute to **vquotes**! We want to make it as easy as possible for everyone to share meaningful Vietnamese quotes.

### Main Contribution Methods
The easiest way to contribute is through our website or GitHub issues:
1. **Google Form**: [Submit via our Contribution Page](https://vquotes.vercel.app/contribute) (No GitHub account required)
2. **GitHub Issues**: [Open a New Quote issue](https://github.com/bbinarygo/vquotes-data/issues/new?template=new-quote.yml) using our template.

All contributions are manually reviewed for accuracy and legal compliance with Vietnamese law (only publicly verifiable sources, no historical distortion).

---

## Tiếng Việt
Cảm ơn bạn đã muốn đóng góp vào **vquotes**! Chúng tôi muốn việc đóng góp trở nên dễ dàng nhất có thể cho tất cả mọi người.

### Cách đóng góp chính
Cách dễ nhất để đóng góp là thông qua trang web hoặc GitHub issues:
1. **Google Form**: [Gửi qua trang Đóng góp](https://vquotes.vercel.app/contribute) (Không cần tài khoản GitHub)
2. **GitHub Issues**: [Mở Issue Báo trích dẫn mới](https://github.com/bbinarygo/vquotes-data/issues/new?template=new-quote.yml) sử dụng template có sẵn.

Mọi đóng góp sẽ được duyệt thủ công để đảm bảo tính chính xác và tuân thủ pháp luật Việt Nam.

---

## Advanced: Direct Pull Request
If you are familiar with Git and JSON, you can contribute directly by following these steps:

1. **Fork** this repository.
2. **Create a new JSON file** inside the `/quotes/` folder. Use the existing files as a reference or follow the schema.
3. **Commit** your changes with a clear and descriptive message.
4. **Open a Pull Request** for review.

**Note:** We only accept quotes with clear public sources. See the JSON files in `/quotes/` for examples of the required format.
